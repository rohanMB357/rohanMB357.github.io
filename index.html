Post-Quantum Cryptography for Federated Learning

Undergraduate thesis · Security + ML

Goal

Measure what it costs to protect federated learning model updates with quantum-resistant encryption.

Approach

Designed three hybrid schemes (ML-KEM, ML-DSA, AES-256) at NIST levels 1, 3 and 5, and ran them over a dedicated secure socket beside a Flower training pipeline.

Challenge

Lab PCs had no admin rights, so a VM-based normalization was impossible. I switched to a per-client ratio analysis across identically configured machines.

Result

20 clientsA working multi-machine testbed with HKDF-SHA-256 key derivation, an acknowledgement handshake and nanosecond timing for every crypto step.

  • Python
  • Flower
  • ML-KEM
  • ML-DSA
  • AES-256
  • HKDF
  • Sockets

Predicting Penalties Won in Football

Independent research · ML

Goal

Find out why some Premier League teams win more penalties than others in a season.

Approach

Built an original dataset from FBref, FotMob and FPL across 5 seasons, engineered features for build-up, creation and forward threat, then compared Linear Regression and XGBoost with 5-fold cross-validation.

Challenge

Three providers had to be merged into one consistent table of 100 team-seasons and about 550 players per season before any modelling could start.

Result

21% betterthan baseline, with RMSE 1.908 and 45 of 100 predictions within one penalty. Error analysis found an individual penalty-specialist effect behind the biggest misses.

  • Python
  • pandas
  • scikit-learn
  • XGBoost
  • Cross-validation

Multi-Genre Music Generation

Course project · Deep learning

Goal

Generate new music across genres using unsupervised deep generative models.

Approach

Parsed and tokenized MIDI across 5 genres, then trained an LSTM autoencoder, a VAE and an autoregressive Transformer decoder.

Challenge

Music has no single correct answer, so I compared models against random and Markov chain baselines and used human survey scores as a reward signal.

Result

3 modelstrained and compared, with the Transformer fine-tuned through RLHF-style policy gradient and samples exported back to playable MIDI.

  • PyTorch
  • LSTM
  • VAE
  • Transformer
  • RLHF

Network Design and Socket Programming

Team course project · Networking

Goal

Build working client-server communication and design a realistic multi-router network.

Approach

Wrote TCP and UDP client-server programs in Python and modelled the network in Cisco Packet Tracer.

Challenge

Getting routing right across several routers, including serial DCE links between them, so every network could reach the others.

Result

TCP + UDPapplications plus a routed multi-router topology, delivered with a team report and a shared work plan.
